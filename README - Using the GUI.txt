##### Introduction
This README segment covers information about using the GUI that the program will open

##### Provided Images
Images have been provided in the './test_images' folder, these include original images with full and valid number plates
as well as images used during the testing section which is highlighted in the report.

##### Selecting an Image
Once the GUI has been opened, an image (.jpg, .jpeg, .png) will have to be selected. This can be done in 2 ways:
1) Click on the 'Select File' button - this will open a file explorer where an image can be selected and opened.
2) Entering or pasting the ABSOLUTE file path including the file name and extension into the 'Image Path' entry Box.

##### Running the Program
Once an image has been selected, the program has to be started, this can also be done in 2 ways:
1) Click on the green button labelled 'Start' - this remain white whilst the program is running.
2) Press the 'Enter' button on the keyboard - This works, however is not recommended as you cannot tell if the program is running or not.
NOTE - If the window becomes unresponsive or shows 'not responding', please wait and do not close the window - this
happens as when the image is being processed, tkinter is not active.
OUTUT - Once an image has been processed, the details will be displayed on screen.

##### Selecting more images
More images can be selected using the button or entry field after one has been processed.
There is no need to close and reopen the program.

##### Exiting the Program
Exiting the program can be done in 2 ways:
1) Click the red button labelled 'Quit' - This will close the window and terminate the code.
2) Press the 'Escape' button on the keyboard - This wil also close the window and terminate the code.
NOTE - Exiting the program is only possible once a number plate has finished being processed.
